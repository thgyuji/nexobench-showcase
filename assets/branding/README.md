# Ícone oficial do Worket

Caixa de ferramentas 3D branca e azul, com a marca `/WKT_`, sobre um quadrado azul escuro arredondado. Foi escolhida a versão da direita do comparativo fornecido pelo autor.

O mestre RGBA de 1254 × 1254 px foi preparado com a ferramenta integrada `image_gen`, isolando o ícone da direita e preservando desenho, cores e texto. Transparência apenas fora do quadrado. Os demais arquivos são exportações mecânicas do mesmo mestre: 512, 256, 192 e 32 px e ICO de 16 a 256 px.

`worket-icon.png` é a versão de 256 px usada no README e na página. `worket-icon-512.png` é a imagem de compartilhamento. Nenhum código ou arquivo de configuração do aplicativo privado é incluído neste showcase.
